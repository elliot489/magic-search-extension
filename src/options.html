Saved app lists

Your Maximo apps are loaded from Maximo when you open it, and again once a day. Type "refresh" in the search box to reload now. Clear removes a list; it's loaded again the next time you open that Maximo.

Environments

Each Maximo server you've used. Pick one to see its apps below, and give it a description to tell them apart. Its sites are used by record search: a word in capitals that is one of them filters the site (e.g. "wo pump BEDFORD"), any other word in capitals filters the status. Sites are loaded from Maximo; add any that are missing as a comma-separated list.

Apps with more than one version

Apps such as Work Order Tracking and Work Order Tracking (Oil), on the environment picked above. Each environment has its own choice and lists only the versions it has. The search box shows only the version chosen here, and its aliases open it.

Aliases and search fields

Short names that open an app, e.g. "wo", listed for the environment picked above (they apply on every environment). Generated from each app's name and id; edit them as a comma-separated list. Reset puts the generated ones back.

The search field is the Maximo attribute that words typed after an app's name search, e.g. "people smith" searches DISPLAYNAME. It's DESCRIPTION for most apps; apps without one have their own default, shown greyed out. Type another attribute to use it instead (e.g. firstname, or item.description through a relationship); clear the field to go back to the default.
